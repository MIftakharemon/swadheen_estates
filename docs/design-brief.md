# Design brief

## Concept

**Quietly bold editorial luxury.** Swadheen is positioned as the steadier, more useful alternative to noisy property portals: a single-vendor team with local knowledge, real information and a human point of view. The visual world is architecture magazine meets modern hospitality brand.

## Palette

- **Ink** `#191F28` — trust, navigation and the dark project moments.
- **Paper** `#F6F2E9` — warm page ground, never clinical white.
- **Stone** `#E8E2D7` — quiet surfaces and filter zones.
- **Terracotta** `#B85B43` — one clear conversion gesture.
- **Moss** `#426356` — verified/available signals and grounded trust.
- **Gold** `#D2A75F` — restrained premium highlight, not decoration everywhere.

Main contrast pairs: ink on paper ~14:1, paper on ink ~15:1, terracotta on paper ~4.8:1, moss on paper ~6.1:1. Status uses text + shape/icon, never colour alone.

## Typography

Cormorant Garamond carries the property narrative with generous, slightly eccentric proportions. Manrope handles UI, numbers and long-form body copy. `Noto Sans Bengali` is loaded as the script fallback so Bangla expansion does not break the system.

## Three differentiating decisions

1. **The catalogue is an edit, not a marketplace wall.** Large type, restrained cards and clear status keep attention on the property rather than ad density.
2. **Trust lives beside conversion.** Verification, title/document language, response promises and human advisor context sit beside every request action.
3. **Experiences are treated as rooms.** 360°, 3D, floor-plan and map surfaces use a minimal control dock and a poster-first fallback so the property stays the hero.

## Hero directions considered

1. **Quiet arrival (selected):** full-bleed warm architecture, oversized serif statement, floating search dock.
2. **The long view:** split-screen property image and long-form editorial statement; strongest for a project launch.
3. **The field guide:** map texture, location labels and a compact property edit; strongest for land-focused campaigns.
